BLIP BASIC

CHAPTER ONE

YOUR FIRST PROGRAM

BASIC lets you give the computer a short list of instructions. Type a line, press RETURN, then ask BLIP to run the lines in order.

10 PRINT "HELLO WORLD"
20 GOTO 10
  1. Type 10 PRINT "HELLO WORLD" and press RETURN.
  2. Type 20 GOTO 10 and press RETURN.
  3. Type RUN to start.
  4. Press ESCAPE to stop and return to BASIC.
LINE NUMBERSThe number at the start tells BASIC where each instruction belongs. Leave gaps—10, 20, 30—so you can add a line later.

Type LIST to see the program. Enter a line again to replace it. NEW deletes the program; CLEAR resets variables and the screen but keeps its lines.

CHAPTER TWO

NUMBERS, CHOICES & LOOPS

A variable is a named place to keep a value. Use words to make a program easier to follow.

10 PLAYER_X=150
20 LIVES=3
30 PRINT "LIVES";LIVES

MAKE A DECISION

10 IF LIVES=0 THEN 100
20 PRINT "PLAYING"
30 GOTO 10
100 PRINT "GAME OVER"

REPEAT A GROUP

10 FOR STAR=1 TO 8
20 PRINT "*";
30 NEXT STAR
40 PRINT

GOTO jumps to a line. GOSUB calls a numbered helper; RETURN comes back. A named SUB, over the page, is easier to read. Put multiple statements on a line with colons. IF … THEN controls the rest of that line.

EXPRESSIONS

+ − * / MOD, comparisons = <> < > <= >=, and AND/OR.

FUNCTIONS

ABS, INT, SQR, SIN, COS, RND, LEN, STR$, COLOR.

BLIP BASIC stores source and string values in capitals. Commands and variable names are case-insensitive.

3
NUMBERS, CHOICES & LOOPS

NAME YOUR ROUTINES.

A SUB is a routine with a name and its own values. Call it by name; BASIC comes back when it reaches END SUB.

10 FOR ROW=0 TO 4
20   CALL STRIPE(ROW*80,"BLIP_CYAN")
30 NEXT ROW
40 END
100 SUB STRIPE(Y,C$)
110   FILL_RECT(0,Y,640,40,C$)
120 END SUB

CALL IT EITHER WAY

CALL STRIPE(0,"BLIP_RED") or just STRIPE 0,"BLIP_RED". Normal flow steps over a SUB; only a call runs it.

ITS OWN VALUES

Parameters and names after LOCAL belong to the call and are put back afterwards. Every other name is shared with the program.

LEAVE EARLYEXIT SUB returns at once. A SUB may call itself: each call keeps its own parameters.

A MOD B is the remainder after dividing, always from 0 up to B: X MOD 640 wraps a position around the screen.

4
NUMBERS, CHOICES & LOOPS

BLOCKS, LOOPS AND DATA.

When a choice needs more than one line, end the IF line with THEN and close the block with END IF.

10 IF LIVES=0 THEN
20   PRINT "GAME OVER"
30 ELSEIF LIVES=1 THEN
40   PRINT "LAST LIFE"
50 ELSE
60   PRINT "PLAYING"
70 END IF

REPEAT WHILE

WHILE X<100 … WEND repeats while the test holds. EXIT FOR leaves a FOR loop early.

A ONE-LINE FUNCTION

DEF FNSQUARE(N)=N*N, then use FNSQUARE(4) in any expression.

KEEP TABLES IN DATA

10 FOR I=1 TO 3:READ NAME$(I),SPEED(I):NEXT I
20 DATA "RYUKA",1.1, "BRUTUS",0.8, "KESTREL",1.36

READ takes the next DATA item; RESTORE 900 starts again at line 900. For text there are MID$(S$,START,LENGTH), LEFT$, RIGHT$, VAL, ASC and CHR$.

BLIP BASIC

CHAPTER THREE

READ INPUT. UPDATE. DRAW.

A game runs one frame at a time. Check the controls, change the game state, and draw a new picture.

10 CLEAR("BLIP_BLACK")
20 IF KEY_HELD("LEFT") THEN PLAYER_X=PLAYER_X-4
30 IF KEY_HELD("RIGHT") THEN PLAYER_X=PLAYER_X+4
40 DRAW_TEXTURE("/TAPE/GFX/BOUNCER/PADDLE.PNG",PLAYER_X,360,100,16)
50 WAIT 16
60 GOTO 10

KEYBOARD CONTROLS

KEY_HELD("LEFT") stays true while a key is down; KEY_PRESSED reads a new press and KEY_ACTIVE either. "SPACE" or "FIRE" is fire, "BUTTON2" is Z, and letters A–G, I, J and K work too. INKEY$ returns a pressed key as text.

WAIT 16 pauses about one frame at 60 frames per second. END finishes the program. ESCAPE and EXIT GAME leave a running game.

COORDINATESThe screen is 640 × 400 pixels, a high-resolution Amiga’s. The origin is at the upper left; x grows right and y grows down. CANVAS(W,H) picks another size: Bubbler keeps its arcade arena, 624 × 600.

READ INPUT. UPDATE. DRAW.

EVERY GAME, THE SAME SHAPE.

Open any tape and you find the same plan. Learn it once and you can find your way round all nine games.

LINES 1–9
What the game is, its keys and its screens. Line 2 says REM GAME: and the game’s name.
LINE 10 · SETUP
Sizes, speeds and colours, each with a name. Music starts at line 80; line 85 picks the first screen.
LINE 100 · MAIN LOOP
Read the keys, update the screen we are on, draw it, WAIT 0, and round again.
LINE 1000 ON
A section for each screen and each thing in the game, under a REM --- heading.
130 IF STATE$="TITLE" THEN
131   UPDATE_TITLE
132 ELSEIF STATE$="PLAY" THEN
133   UPDATE_PLAY
134 ELSE
135   UPDATE_OVER
136 END IF

Each screen is a pair of routines: UPDATE_PLAY changes the game and DRAW_PLAY paints it. START_GAME sets up a new game. A routine’s body is indented two spaces, and a line holds one statement.

READ INPUT. UPDATE. DRAW.

NAMES THAT TELL.

A good name says what a routine does, so a routine that calls others reads like a list of jobs.

4210 SUB UPDATE_PLAY
4220   MOVE_PLAYERS
4230   MOVE_TOYS
4240   MOVE_BUBBLES
4250   HURT_PLAYERS
4260 END SUB

VERB FIRST

MOVE_, DRAW_, START_, FIRE, POP_CHAIN: say what happens. The plural moves them all; the singular moves one, MOVE_TOY I.

QUESTIONS AS FN

A DEF FN answers yes or no: FNIN_PLAY(P), FNBLOCK(C,R). Read it aloud in an IF.

THE SAME NAMES IN RUST

The arcade games are written in Rust to the same plan, with update_play, draw_play and start_game. Read a tape, then its Rust game, and the parts line up.

SAY WHY, NOT WHATA REM earns its place with a rule or a reason, such as “A JUMP IS TOLD BEFORE IT HAPPENS”. The code already says what it does.

THE CONVERSION CAPERS

CHAPTER FOUR

THE ARCADE DOESN’T FIT

An arcade game is tuned to its own cabinet. Bringing it home means rebuilding it around a smaller memory, a different screen, new controls and a very different sound chip.

KEEPTHE GAME’S RHYTHMMovement, danger, reward
›
RETHINKWHAT THE MACHINE CAN DOScreen, colour, memory, time
›
REBUILDTHE FEELINGClear cues, responsive play

THE HARD PART IS THE TRADE-OFF

Fewer colours may change a scene; slower drawing can change the timing; one-button controls can change a move. A faithful screenshot is not enough if the game no longer feels right. Good conversions simplify detail, protect the essential motion, and keep the controls immediate.

THE CONVERSION CAPERSRetro Gamer issue 164 praises the CPC Gauntlet II for combining C64-like detail with Spectrum-like speed. Issue 178’s Enduro Racer comparison shows the other side: similar graphics cannot hide slower, less responsive play.

For Mev Dinc, Alan Laird, and the programmers, artists, composers and testers who made each machine feel like a place arcade games could live.

BLIP BASIC

CHAPTER FIVE

DRAW WITH BLIP

Each primitive is a statement on a numbered line, measured in game pixels and named as in the Rust BLIP crate.

CLEAR(COLOR)

Fill the screen with one colour.

FILL_RECT(X,Y,W,H,COLOR)

Draw a solid rectangle.

DRAW_RECT(X,Y,W,H,COLOR)

Draw a one-pixel outline.

DRAW_LINE(X1,Y1,X2,Y2,COLOR)

Draw a one-pixel line.

DRAW_LINE_EX(X1,Y1,X2,Y2,WIDTH,COLOR)

Draw a line with a chosen thickness.

DRAW_GLOW_LINE(X1,Y1,X2,Y2,COLOR)

A bright line with a soft halo.

FILL_CIRCLE(CX,CY,R,COLOR)

A filled circle from centre and radius.

DRAW_CIRCLE(CX,CY,R,COLOR[,WIDTH])

A ring: the outline of a circle.

FILL_CAPSULE(X1,Y1,X2,Y2,R1,R2,COLOR)

A tapered capsule between two points.

FILL_SUNBURST(CX,CY,RAYS,TURN,REACH,COLOR_A,COLOR_B)

Alternating rays; TURN is radians.

FILL_GLOW_CIRCLE(CX,CY,R,COLOR)

A soft halo around a bright core.

DRAW_CHAR(CHAR,X,Y,SIZE,COLOR)

One character in the BLIP pixel font.

DRAW_TEXT(TEXT,X,Y,SIZE,COLOR[,ALIGN[,OUTLINE]])

ALIGN is LEFT or CENTER; OUTLINE adds an ink colour.

DRAW_NUMBER(N,X,Y,SIZE,COLOR)

Draw an integer directly.

DRAW_HUD(SCORE,LIVES)

The standard BLIP score and lives bar.

TEXT_CX(TEXT,SIZE)

The x coordinate that centres text.

A colour is a name like "BLIP_CYAN", a palette number 0–7, COLOR(R,G,B[,A]) from 0 to 1, or hex "#36A9D6".

SOUND & MUSIC

CHAPTER SIX

SOUND & MUSIC

Use short effects for game events, and leave room for each new sound to be heard.

100 PLAY_SFX "SERPENT/EAT",0.8
110 SOUND 660,0.12,0.5
120 PLAY_MUSIC "SERPENT_MAIN"
130 REST 0.2
SOUND HZ,SECONDS[,VOLUME]
Play a simple tone. Volume is from 0 to 1.
PLAY_SFX "GAME/EFFECT"[,VOLUME]
Play one of a game’s own effects. Banks: ADDER, BOUNCER, BRAWLER, BUBBLER, GALACTIC_DEFENDER, METEORS, RALLY, SERPENT and SKY_RAIDER.
REST SECONDS
Pause between notes and effects.
PLAY_MUSIC NAME
Start a loop: a built-in track name or a saved path such as "/USER/MUSIC/SONG.TUNE".
STOP_MUSIC
Stop the current music track.

To make a loop of your own, enter TUNE: over the page.

Names are checked when the program runs. An unknown effect or track reports an error.

11
SOUND & MUSIC

WRITE A TUNE.

TUNE opens a small tracker: four chip voices, each playing down sixteen steps.

  1. Enter TUNE.
  2. Choose a NOTE, from C2 to B5.
  3. Click a cell to put the note there; click again to clear it. The rows are the voices: square, pulse, triangle and noise.
  4. ▶ adds a pattern and PAT moves between them, up to 32. BPM sets the speed, from 50 to 240.
  5. PLAY listens and STOP stops.
  6. Name it, for example /USER/MUSIC/THEME.TUNE, and SAVE.
80 PLAY_MUSIC "/USER/MUSIC/THEME"

SAVE keeps the notes in THEME.TUNE, to edit later, and the sound in THEME.WAV, which PLAY_MUSIC plays round and round. Change line 80 in your copy of a game and it plays your theme.

FROM A TRACKERIMPORT XM brings in the notes of a MilkyTracker module: its first four channels and up to 32 patterns, at its tempo. BLIP’s chip voices play them.

CHAPTER SEVEN

THE /TAPE/GFX DRAWER

The tapes carry the games’ pictures too, a folder for each game, ready to draw.

LOAD /TAPE/BOUNCER.BLIP
DIR /TAPE/GFX
DIR /TAPE/GFX/BOUNCER
DRAW_TEXTURE("/TAPE/GFX/BOUNCER/BALL.PNG",X,Y,8,8)
DRAW_TEXTURE(FILE,X,Y,W,H[,TINT])

Stretch an image; optionally multiply it by a tint.

DRAW_TEXTURE(FILE,X,Y,W,H,SX,SY,SW,SH)

Crop a pixel rectangle from an image and stretch it into the destination.

DRAW_TEXTURE(FILE,X,Y,W,H,COL,COLS,ROW,ROWS,ANGLE)

Draw one sprite-sheet cell; rotation is radians.

Texture names are full paths, for example /TAPE/GFX/GALACTIC_DEFENDER/ALIEN_SQUID_A.PNG. Drawing is clipped to the screen.

PICTURE LIBRARYEvery game has a folder: ADDER · BOUNCER · BRAWLER · BUBBLER · GALACTIC_DEFENDER · METEORS · RALLY · SERPENT · SKY_RAIDER.
13
THE /TAPE/GFX DRAWER

PAINT YOUR OWN.

PAINT opens a pixel editor on the monitor. Each picture is a PNG file in your /USER drawer.

PEN · ERASE

Draw or clear pixels; drag to draw a line.

FILL · PICK

Flood an area with the colour, or pick a colour up from the picture.

UNDO · CLEAR

Step back, up to thirty times, or start again.

SIZE

From 16 × 16 for a sprite to 320 × 200 for a scene.

PAINT /USER/GFX/HERO.PNG
… draw, SAVE, then DONE …
10 CLEAR("BLIP_BLACK")
20 DRAW_TEXTURE("/USER/GFX/HERO.PNG",304,184,32,32)
30 WAIT 0:GOTO 10

Erased pixels are see-through, so a sprite shows the scene behind it. Draw small and let DRAW_TEXTURE make it bigger: a 16 × 16 sprite drawn at 32 × 32 keeps sharp, square pixels.

THE /TAPE/GFX DRAWER

REPAINT A GAME.

A tape’s pictures are read-only, but your own copy of a game is yours to repaint.

  1. Enter LOAD /TAPE/BUBBLER.BLIP, then RUN.
  2. Press ESCAPE. BASIC copies the game to /USER/BUBBLER/BUBBLER.BLIP and its pictures to /USER/BUBBLER/GFX, then opens the copy in the editor.
  3. Enter PAINT /USER/BUBBLER/GFX/ROBOT.PNG, change the robot, SAVE, then DONE.
  4. Enter RUN. The robots wear your paint.
45 GFX$="/USER/BUBBLER/GFX/"

In the copy, the line that named the tape’s picture folder now names yours, so every picture comes from your drawer. Keep a picture the same size and the game keeps its spacing.

START AGAINDelete a picture with DEL and draw it fresh, or load the tape again: the original is never changed.

BLIP BASIC

CHAPTER NINE

OPEN A GAME. STUDY ITS SOURCE.

The games in /TAPE are ordinary BLIP BASIC source files. Load one, read it, then make a copy in your own drawer before changing it.

FIND AND RUN A GAME

DIR /TAPE
LOAD /TAPE/BOUNCER.BLIP
RUN

Choose a cassette from the pile, or use LOAD /TAPE/BOUNCER.BLIP to insert it. DIR /TAPE lists only that cassette’s files. Ejecting it removes those files from the directory. LOAD puts its source into memory; RUN starts it. Press ESCAPE to stop a running game and return to BASIC.

LEARN FROM GAMES

READ THE SOURCE. MAKE A COPY.

READ BEFORE YOU CHANGE

LOAD /TAPE/BOUNCER.BLIP
SOURCE
LIST

SOURCE prints the program; LIST shows its numbered lines. Start with the lines at the top, then the main loop at line 100, then each screen’s UPDATE_ and DRAW_ routine. REM starts a comment: everything after it, including colons, is ignored. Use comments to name sections and explain state.

MAKE YOUR OWN COPY

LOAD /TAPE/BOUNCER.BLIP
SAVE MY_BOUNCER
EDIT /USER/MY_BOUNCER.BLIP
RUN

SAVE MY_BOUNCER writes the source to /USER/MY_BOUNCER.BLIP. Keep its REM GAME: line so the copy uses the same controls. Files in /USER stay in this browser.

BLIP BASIC

CHAPTER TEN

MOVE, TYPE, SAVE AS YOU GO

EDIT FILE opens a full-screen source editor on the monitor, for example EDIT /USER/MY_BOUNCER.BLIP. It opens an existing file or creates a new one under /USER.

ARROW KEYS

Move the caret. Up and down keep it as near as possible to the same column.

HOME / END

Move to the start or end of the line.

TYPE / RETURN

Insert uppercase text at the caret. RETURN splits the line.

BACKSPACE / DEL

Remove text. At a line boundary, the line joins its neighbour.

TAB

Accept the dimmed completion suggestion, or insert spaces.

ESCAPE

Close the editor and return to the BASIC prompt.

Every edit is saved to the open /USER file. Keywords and strings are highlighted; dimmed completion text joins the source only when you press TAB.

USING THE EDITOR

TRY A CHANGE. RUN IT.

Change one small thing, press ESCAPE, then enter RUN. If the game behaves differently than you expect, reopen the file and correct the line.

EDIT /USER/MY_BOUNCER.BLIP
… change a speed or a colour, then ESCAPE …
RUN

KEEP A CLEAN COPY

Before a larger experiment, load the tape again and use SAVE BOUNCER_SAFE. You can always begin again from the untouched example.

THE ORIGINAL IS SAFEOnly files in /USER can be edited or deleted. A tape is never overwritten.
