BLIP BASIC

CHAPTER ONE

YOUR FIRST PROGRAM

BASIC lets you give the computer a short list of instructions. Type a line, press RETURN, then ask BLIP to run the lines in order.

10 PRINT "HELLO WORLD"
20 GOTO 10
  1. Type 10 PRINT "HELLO WORLD" and press RETURN.
  2. Type 20 GOTO 10 and press RETURN.
  3. Type RUN to start.
  4. Press ESCAPE to stop and return to BASIC.
LINE NUMBERSThe number at the start tells BASIC where each instruction belongs. Leave gaps—10, 20, 30—so you can add a line later.

Type LIST to see the program. Enter a line again to replace it. NEW deletes the program; CLEAR resets variables and the screen but keeps its lines.

NUMBERS, CHOICES & LOOPS

CHAPTER TWO

NUMBERS, CHOICES & LOOPS

A variable is a named place to keep a value. Use words to make a program easier to follow.

10 PLAYER_X=150
20 LIVES=3
30 PRINT "LIVES";LIVES

MAKE A DECISION

10 IF LIVES=0 THEN 100
20 PRINT "PLAYING"
30 GOTO 10
100 PRINT "GAME OVER"

REPEAT A GROUP

10 FOR STAR=1 TO 8
20 PRINT "*";
30 NEXT STAR
40 PRINT

GOTO jumps to a line. GOSUB calls a helper routine; RETURN comes back. Put multiple statements on a line with colons. IF … THEN controls the rest of that line.

EXPRESSIONS

+ − * /, comparisons = <> < > <= >=, and AND/OR.

FUNCTIONS

ABS, INT, SQR, SIN, COS, RND, LEN, STR$, COLOR.

BLIP BASIC stores source and string values in capitals. Commands and variable names are case-insensitive.

BLIP BASIC

CHAPTER THREE

READ INPUT. UPDATE. DRAW.

A game runs one frame at a time. Check the controls, change the game state, and draw a new picture.

10 CLEAR("BLIP_BLACK")
20 IF KEY_HELD("LEFT") THEN PLAYER_X=PLAYER_X-2
30 IF KEY_HELD("RIGHT") THEN PLAYER_X=PLAYER_X+2
40 DRAW_TEXTURE("/TAPE/GFX/BOUNCER/PADDLE.PNG",PLAYER_X,180,50,8)
50 WAIT 16
60 GOTO 10

KEYBOARD CONTROLS

KEY_HELD("LEFT") stays true while a key is down; KEY_PRESSED reads a new press and KEY_ACTIVE either. "SPACE" or "FIRE" is fire, "BUTTON2" is Z, and letters A–G, I, J and K work too. INKEY$ returns a pressed key as text.

WAIT 16 pauses about one frame at 60 frames per second. END finishes the program. ESCAPE and EXIT GAME leave a running game.

COORDINATESThe drawing area is 320 × 200 pixels, the BLIP crate’s game coordinates. The origin is at the upper left; x grows right and y grows down.

THE CONVERSION CAPERS

CHAPTER FOUR

THE ARCADE DOESN’T FIT

An arcade game is tuned to its own cabinet. Bringing it home means rebuilding it around a smaller memory, a different screen, new controls and a very different sound chip.

KEEPTHE GAME’S RHYTHMMovement, danger, reward

RETHINKWHAT THE MACHINE CAN DOScreen, colour, memory, time

REBUILDTHE FEELINGClear cues, responsive play

THE HARD PART IS THE TRADE-OFF

Fewer colours may change a scene; slower drawing can change the timing; one-button controls can change a move. A faithful screenshot is not enough if the game no longer feels right. Good conversions simplify detail, protect the essential motion, and keep the controls immediate.

THE CONVERSION CAPERSRetro Gamer issue 164 praises the CPC Gauntlet II for combining C64-like detail with Spectrum-like speed. Issue 178’s Enduro Racer comparison shows the other side: similar graphics cannot hide slower, less responsive play.

For Mev Dinc, Alan Laird, and the programmers, artists, composers and testers who made each machine feel like a place arcade games could live.

CHAPTER FIVE

DRAW WITH BLIP

Each primitive is a statement on a numbered line, measured in game pixels and named as in the Rust BLIP crate.

CLEAR(COLOR)

Fill the screen with one colour.

FILL_RECT(X,Y,W,H,COLOR)

Draw a solid rectangle.

DRAW_RECT(X,Y,W,H,COLOR)

Draw a one-pixel outline.

DRAW_LINE(X1,Y1,X2,Y2,COLOR)

Draw a one-pixel line.

DRAW_LINE_EX(X1,Y1,X2,Y2,WIDTH,COLOR)

Draw a line with a chosen thickness.

DRAW_GLOW_LINE(X1,Y1,X2,Y2,COLOR)

A bright line with a soft halo.

FILL_CIRCLE(CX,CY,R,COLOR)

A filled circle from centre and radius.

FILL_CAPSULE(X1,Y1,X2,Y2,R1,R2,COLOR)

A tapered capsule between two points.

FILL_SUNBURST(CX,CY,RAYS,TURN,REACH,COLOR_A,COLOR_B)

Alternating rays; TURN is radians.

FILL_GLOW_CIRCLE(CX,CY,R,COLOR)

A soft halo around a bright core.

DRAW_CHAR(CHAR,X,Y,SIZE,COLOR)

One character in the BLIP pixel font.

DRAW_TEXT(TEXT,X,Y,SIZE,COLOR[,ALIGN[,OUTLINE]])

ALIGN is LEFT or CENTER; OUTLINE adds an ink colour.

DRAW_NUMBER(N,X,Y,SIZE,COLOR)

Draw an integer directly.

DRAW_HUD(SCORE,LIVES)

The standard BLIP score and lives bar.

TEXT_CX(TEXT,SIZE)

The x coordinate that centres text.

A colour is a name like "BLIP_CYAN", a palette number 0–7, COLOR(R,G,B[,A]) from 0 to 1, or hex "#36A9D6".

SOUND & MUSIC

CHAPTER SIX

SOUND & MUSIC

Use short effects for game events, and leave room for each new sound to be heard.

100 PLAY_SFX "SERPENT/EAT",0.8
110 SOUND 660,0.12,0.5
120 PLAY_MUSIC "SERPENT_MAIN"
130 REST 0.2
SOUND HZ,SECONDS[,VOLUME]
Play a simple tone. Volume is from 0 to 1.
PLAY_SFX "GAME/EFFECT"[,VOLUME]
Play one of a game’s own effects. Banks: ADDER, BOUNCER, BRAWLER, BUBBLER, GALACTIC_DEFENDER, METEORS, RALLY, SERPENT and SKY_RAIDER.
REST SECONDS
Pause between notes and effects.
PLAY_MUSIC NAME
Start a loop: a built-in track name or a saved path such as "/USER/MUSIC/SONG.TUNE".
STOP_MUSIC
Stop the current music track.

Enter TUNE to make a four-voice loop with 16-step patterns. Select a note and click a cell to add or clear it. Import an XM module from MilkyTracker to bring in up to 32 pages of notes from its first four channels, in order and at its tempo. XM samples and effects are not retained; BLIP chip voices replace the instruments. Save the editable .TUNE and its WAV playback file under /USER/MUSIC.

Names are checked when the program runs. An unknown effect or track reports an error.

CHAPTER SEVEN

THE /TAPE/GFX DRAWER

The tapes carry the games’ pictures too, a folder for each game, ready to draw.

LOAD /TAPE/BOUNCER.BLIP
DIR /TAPE/GFX
DIR /TAPE/GFX/BOUNCER
DRAW_TEXTURE("/TAPE/GFX/BOUNCER/BALL.PNG",X,Y,8,8)
DRAW_TEXTURE(FILE,X,Y,W,H[,TINT])

Stretch an image; optionally multiply it by a tint.

DRAW_TEXTURE(FILE,X,Y,W,H,SX,SY,SW,SH)

Crop a pixel rectangle from an image and stretch it into the destination.

DRAW_TEXTURE(FILE,X,Y,W,H,COL,COLS,ROW,ROWS,ANGLE)

Draw one sprite-sheet cell; rotation is radians.

Texture names are full paths, for example /TAPE/GFX/GALACTIC_DEFENDER/ALIEN_SQUID_A.PNG. Drawing is clipped to the screen.

PICTURE LIBRARYADDER · BOUNCER · GALACTIC_DEFENDER · SERPENT · SKY_RAIDER. Other games draw their shapes with BLIP primitives.

CHAPTER EIGHT

SAVE YOUR PROGRAMS

DIR [PATH]
List a directory: /TAPE, /TAPE/GFX or /USER.
CD [PATH]
Change directory; no path returns to /USER.
MKDIR NAME
Create a folder under /USER.
LOAD FILE
Load a program from /TAPE or /USER.
EJECT
Stop the program and remove the inserted cassette.
RUN
Run the program in memory.
SAVE [NAME]
Save the current source under /USER.
DEL FILE
Delete a named file under /USER; /TAPE files cannot be deleted.
SOURCE [FILE]
Print the current source or a named program.
EDIT FILE
Edit a /USER file. Changes save as you type; ESCAPE closes it.
PAINT [FILE]
Draw a 320 × 200 image in the monitor and save it as PNG under /USER/GFX.
CD /USER
MKDIR GAMES
CD GAMES
SAVE STARFIELD
DIR

/TAPE shows only the inserted cassette’s program and pictures in /TAPE/GFX; it is empty without a cassette and is read-only. /USER is kept in this browser. File names and saved source are uppercase. Start with PAINT, accept the suggested /USER/GFX/SPRITE.PNG name or enter your own, then use that PNG with DRAW_TEXTURE.

BLIP BASIC

CHAPTER NINE

OPEN A GAME. STUDY ITS SOURCE.

The games in /TAPE are ordinary BLIP BASIC source files. Load one, read it, then make a copy in your own drawer before changing it.

FIND AND RUN A GAME

DIR /TAPE
LOAD /TAPE/BOUNCER.BLIP
RUN

Choose a cassette from the pile, or use LOAD /TAPE/BOUNCER.BLIP to insert it. DIR /TAPE lists only that cassette’s files. Ejecting it removes those files from the directory. LOAD puts its source into memory; RUN starts it. Press ESCAPE to stop a running game and return to BASIC.

LEARN FROM GAMES

READ THE SOURCE. MAKE A COPY.

READ BEFORE YOU CHANGE

LOAD /TAPE/BOUNCER.BLIP
SOURCE
LIST

SOURCE prints the program; LIST shows its numbered lines. Start with the flow map, then follow the section headings and GOSUB helpers. REM starts a comment: everything after it, including colons, is ignored. Use comments to name sections and explain state.

MAKE YOUR OWN COPY

LOAD /TAPE/BOUNCER.BLIP
SAVE MY_BOUNCER
EDIT /USER/MY_BOUNCER.BLIP
RUN

SAVE MY_BOUNCER writes the source to /USER/MY_BOUNCER.BLIP. Keep its REM GAME: line so the copy uses the same controls. Files in /USER stay in this browser.

BLIP BASIC

CHAPTER TEN

MOVE, TYPE, SAVE AS YOU GO

EDIT FILE opens a full-screen source editor on the monitor, for example EDIT /USER/MY_BOUNCER.BLIP. It opens an existing file or creates a new one under /USER.

ARROW KEYS

Move the caret. Up and down keep it as near as possible to the same column.

HOME / END

Move to the start or end of the line.

TYPE / RETURN

Insert uppercase text at the caret. RETURN splits the line.

BACKSPACE / DEL

Remove text. At a line boundary, the line joins its neighbour.

TAB

Accept the dimmed completion suggestion, or insert spaces.

ESCAPE

Close the editor and return to the BASIC prompt.

Every edit is saved to the open /USER file. Keywords and strings are highlighted; dimmed completion text joins the source only when you press TAB.

12
USING THE EDITOR

TRY A CHANGE. RUN IT.

Change one small thing, press ESCAPE, then enter RUN. If the game behaves differently than you expect, reopen the file and correct the line.

EDIT /USER/MY_BOUNCER.BLIP
… change a speed or a colour, then ESCAPE …
RUN

KEEP A CLEAN COPY

Before a larger experiment, load the tape again and use SAVE BOUNCER_SAFE. You can always begin again from the untouched example.

THE ORIGINAL IS SAFEOnly files in /USER can be edited or deleted. A tape is never overwritten.

CLAMP(V,LO,HI) keeps a value in bounds. LERP(A,B,T) blends positions; WRAP(V,LO,HI) wraps them. DISTANCE(X0,Y0,X1,Y1) measures a gap. SCATTER(I,SALT) places repeatable scenery. These functions use the native games’ Rust helpers.
