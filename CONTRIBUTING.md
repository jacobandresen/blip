# Contributing

Pull requests are welcome at [github.com/jacobandresen/blip](https://github.com/jacobandresen/blip).
[AGENTS.md](AGENTS.md) describes how to add a game and how to test it.

## Tributes, not copies

- Write mechanics, art and sound from scratch; never copy proprietary code, graphics or audio.
- Use your own names: Rally, not Pong; Serpent, not Snake.
- Add something of your own beyond the original.
